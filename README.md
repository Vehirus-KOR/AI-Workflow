# AI-Workflow

## 주요 학습 내용

* **n8n** — Workflow 구성 및 자동화
* **API** — REST API, Webhook을 활용한 서비스 연동
* **MCP** — AI 모델과 외부 Tool 및 데이터 연결
* **LangChain** — LLM 기반 애플리케이션 및 Workflow 구성
* **Workflow** — 데이터 수집, 처리, 전달 과정 자동화
* **Docker** — 실습 환경 구축 및 서비스 실행
* **GitHub** — 소스 코드 및 실습 버전 관리

## Language & Data

* Python
* JSON

## Workflow Example

```text
Client / API
     ↓
   Webhook
     ↓
    n8n
     ↓
Data Processing
     ↓
AI / External API
     ↓
Database / Google Sheets
```

## Purpose

API, AI 모델, 데이터 및 외부 서비스를 연결하여 **데이터 처리와 AI 서비스의 전체 Workflow를 구축하고 자동화하는 방법**을 학습하는 것을 목표로 합니다.
